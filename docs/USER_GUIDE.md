# General user guide

[Back to the overview](../README.md)

This guide describes the intended use of the local standalone reviewer. It does not publish the confidential model or decision implementation.

1. [Download the Windows application](https://github.com/Witchayada-T/Transfer-pricing-preliminary-risk-indicator/releases/download/standalone-v1.2/TransferPricingReviewer.exe), or the ZIP with this guide. Extract the ZIP before opening the executable. No Python installation is required.
2. Open `TransferPricingReviewer.exe` locally and leave its controller window open. A browser opens the application on this computer. Closing the controller stops the local server. Startup includes unpacking the runtime and may take a little time. No company financial information should be uploaded to this public repository.
3. Enter the company identity, business activity and the financial information the reviewer is authorised to use. Explain the company’s functions and commercial circumstances where known.
4. Read the financial-pattern result and the company-context review separately. A result outside the reference scope should remain unassessed rather than being forced into another industry.
5. Check source figures, missing information and any business explanation before deciding what further work is needed.
6. Retain a review record only through the application’s explicit export function, and handle it according to the company’s confidentiality requirements.

The standalone tool is a preliminary aid. A flagged pattern can be commercially explainable. It is the supporting evidence and the relevant facts—not the existence of a flag alone—that inform a defensible transfer-pricing assessment.

## Review the summary

The summary states what drew attention and what needs checking. Consider the actual functions, assets and risks, the source accounts, the related-party dealings and any documented commercial explanation. An explanation can make an unusual result understandable; entering it does not verify it or automatically clear the original signal. Unknown information stays visible.

## Download or startup problems

The release provides both a direct executable and a ZIP. The application is unsigned. If your browser, Windows or an organisation's security policy blocks it, use an approved IT review/distribution route. Include the Windows version and exact error when requesting help; omit confidential inputs and credentials.
