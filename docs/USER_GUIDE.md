# General user guide

[Back to the overview](../README.md)

This guide describes the intended use of the local standalone reviewer. It does not publish the confidential model or decision implementation.

1. Obtain the approved standalone package through the authorised sharing route. Extract the complete package and keep its required runtime files together.
2. Open the application locally. No company financial information should be uploaded to this public repository.
3. Enter the company identity, business activity and the financial information the reviewer is authorised to use. Explain the company’s functions and commercial circumstances where known.
4. Read the financial-pattern result and the company-context review separately. A result outside the reference scope should remain unassessed rather than being forced into another industry.
5. Check source figures, missing information and any business explanation before deciding what further work is needed.
6. Retain a review record only through the application’s explicit export function, and handle it according to the company’s confidentiality requirements.

The standalone tool is a preliminary aid. A flagged pattern can be commercially explainable. It is the supporting evidence and the relevant facts—not the existence of a flag alone—that inform a defensible transfer-pricing assessment.
