Transfer Pricing Preliminary Risk Indicator

A local aid for preliminary review. Machine learning identifies unusual financial patterns; it does not decide whether transfer pricing is wrong.

Download Windows application · Back to project page

Run locally

Open the Windows executable and keep the controller window open while using the application in the browser. No Python installation is required. Closing the controller stops the local server. The first start includes unpacking the runtime.

What a reviewer considers

  • The company’s business activity and financial position.
  • Its functions, assets, risks and related-party transactions.
  • Whether a documented commercial explanation accounts for the result.
  • The relevant OECD guidance and applicable Thai law.

How to read the result

A flag calls for review. It is not proof of non-compliance. A commercially supported explanation may make a flagged position defensible; missing information is not a pass.

Confidentiality

Technical model details, source code, numerical rules and company-level evidence are not included in this public-facing overview. Only the compiled application is shared; no separate source code, model files or collected-company tables are offered. An offline executable contains its runtime logic and parameters, which may be extractable.
